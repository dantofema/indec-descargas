Servicios geoespaciales del INDEC

Qué publica el INDEC más allá de este sitio, y cómo consumirlo directamente.

WFS 2.0.0

Endpoint: https://geonode.indec.gob.ar/geoserver/ows. CORS abierto — es de lo que depende este sitio.

Capas vectoriales

Diez capas, todas bajo el prefijo geonode:. Este sitio usa ocho; las dos versiones "puntos" no.

  • geonode:aglomerados usa este sitio
  • geonode:departamentos usa este sitio
  • geonode:fracciones_censales usa este sitio
  • geonode:gobiernos_locales4 usa este sitio
  • geonode:gobiernos_locales_puntos no usa este sitio
  • geonode:jurisdicciones usa este sitio
  • geonode:localidades_censales usa este sitio
  • geonode:localidades_censales_puntos1 no usa este sitio
  • geonode:radios_censales2 usa este sitio
  • geonode:vias_de_circulacion usa este sitio

Formatos de salida

  • geopackage (alias gpkg, geopkg, application/x-gpkg)
  • application/json (GeoJSON)
  • SHAPE-ZIP
  • csv
  • excel
  • excel2007
  • KML
  • GML 2 / 3.1.1 / 3.2

WMS 1.3.0

Mismo endpoint, mismas diez capas.

image/png entre los formatos de GetMap, más salidas que no son imagen: application/pdf, KML/KMZ, GeoJSON, TopoJSON y application/vnd.mapbox-vector-tile.

CRS soportados: EPSG:4326, EPSG:3857, CRS:84 y otros.

GeoNode / Geoportal INDEC

https://geonode.indec.gob.ar/ es el Geoportal INDEC.

Publica 47 capas, contra las 8 que usa este sitio, más mapas, documentos y metadatos.

OpenSearch: /catalogue/opensearch

Dos recetas

Conectar el WFS en QGIS

  1. Capa → Añadir capa → WFS
  2. Pegar el endpoint: https://geonode.indec.gob.ar/geoserver/ows

Pedir una capa desde código

La misma forma que arma este sitio: CQL_FILTER con el campo y el código entre comillas simples.

https://geonode.indec.gob.ar/geoserver/ows?service=WFS&version=2.0.0&request=GetFeature&typenames=geonode:departamentos&outputFormat=application/json&srsName=EPSG:4326&CQL_FILTER=cde='06840'
